# Data-Structures-usecases
 Repo holds multiple test cases for applying data structures
## Data Structures used
1. Maps
2. Sets
3. Arrays
4. Lists
5. Trees
## Use cases
1. The data structures are tested on Search algorithms for checking which provides best performance for a specific case
2. They are tested on sorting algorithms to identify the performance and case specific requirements

## Measures of Performance
1. Time of executing algorithm
2. Memory used
3. Structure of algorithm
